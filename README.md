\# Wi-Fi Security — Deauthentication Attack Simulation



\## Overview



A controlled Wi-Fi security laboratory project demonstrating IEEE 802.11 wireless management frame analysis using Wireshark.



The investigation focuses on authentication, association, normal wireless traffic, and deauthentication frame analysis.



> \*\*Important:\*\* The presence of a deauthentication frame does not by itself prove a malicious attack. Findings in this project are based only on the observed packet capture and documented frame fields.



---



\## Objective



The objectives of this laboratory are to understand:



\- IEEE 802.11 management frames

\- Open System authentication

\- Association request and response

\- Deauthentication frames

\- Deauthentication reason codes

\- Wireless packet filtering

\- Packet-level investigation

\- Evidence-based security analysis



---



\## Environment



\- Controlled / authorized training analysis

\- Windows

\- Wireshark

\- IEEE 802.11 sample packet capture
